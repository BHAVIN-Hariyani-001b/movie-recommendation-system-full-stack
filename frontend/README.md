Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## Movie API

The frontend calls the movie service through same-origin Next.js route handlers, so the backend does not need browser CORS changes. By default, the service is expected at `http://localhost:8000`.

To use a different backend URL, set `MOVIE_API_URL` in a local `.env.local` file:

```env
MOVIE_API_URL=http://localhost:8000
```

Restart the frontend after changing this value. The frontend uses `/health`, `/movie/top30?page=1&limit=10`, and `/movie/predict/{id}` on the backend. The top-movies endpoint should return `movies`, `page`, `limit`, `total`, and `total_pages`; the frontend preloads the next page for faster navigation and limits browsing to the first 150 movies.
